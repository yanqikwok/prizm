# Source screens

Exported screens the proposed components are extracted from. **Everything in this folder except
this README is git-ignored** — this fork is public, so screens stay on the machine they were
exported to. Copy them to the other MacBook by hand (e.g. AirDrop) when needed.

One folder per screen, with an HTML export where available plus a PNG:

```
contributions/source-screens/<screen-name>/
  screen.png
  screen.html
```

Each component's guideline doc points at its screen through the `source-screen` frontmatter field.
